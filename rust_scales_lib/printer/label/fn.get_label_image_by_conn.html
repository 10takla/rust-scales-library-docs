§Основная функция для получения .bmp этикетки

Алгоритм:

  1. Генерация структуры шаблона со всеми вложенными данными из БД
  2. Создание PrintableData
  3. Отрисовка шаблона по структуре шаблона (1.):
    • (опционально) отрисовка сетки
    • Отрисовка каждого элемента шаблона:

      • Отрисовка текстового элемента [Text]:

        • Отрисовка SpecialText:
          • Получение от менеджера весов (product, weight, tare, date) для генерации тектса
          • Генерация текста
          • Отрисовка текста:
            • если пустая строка, то return
            • разделение текста по строкам
            • пройтись по каждой строке
              • пройтись по каждому символу:
                • получение шрифта в зависимости от символа (для символов валют использовать FiraCode-Regular.otf)
                • получение размера глифа
                • по смещению размера глифа к целевому размеру:
                  • получение итоговой позции символа
                  • получение итогового рамера символа
                • отрисовать символ
        • Отрисовка GlobalText

      • Отрисовка штрихкодов, qr кодов и datamatrix [Barcode]:

        • Получение от менеджера весов (weight, tare, quantity) для генерации шртихкода
        • Генерация штрихкода
        • (опционально) Отрисовка line_verification
        • Отрисовка кода
        • Отрисовка штрихкода

      • Отрисовка элемента изображения [Image]

      • Отрисовка графического элемента [Graphic]

      • P.S. Для кажого элемента:

        • (опционально) отрисовка фона
        • Смещение позции y на -1
